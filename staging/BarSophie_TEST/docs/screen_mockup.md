## 3-A. ツンデレ動的メニュー（「ソフィーと話す」タップ後）

タップ → 案内音声 →（3秒）→ ランダム2ボタン＋操作ボタン。ソフィーの声で"じらす"演出。

```
┌──────────────────────────────────┐
│  🗨「今夜は、このどちらかで        │  ← sophie_counter_offer
│      いかがですか？」              │
│                                  │
│      ( 歌 )      ( お酒 )         │  ← ランダム2択（ピル型・光る）
│                                  │
│     [ 違うよ ]    [ メニュー見せて ]│  ← 操作ボタン（間隔広め）
└──────────────────────────────────┘
```

**ソフィーのセリフ（音声）：**

| 場面 | セリフ | 音声 |
|------|--------|------|
| 展開時 | 「今夜は、このどちらかでいかがですか？」 | `sophie_counter_offer` |
| 違うよ①| 「あら、違いましたか。では、こちらはいかがですか？」 | `sophie_counter_wrong1` |
| 違うよ②| 「あら、またはずれですか。ではこちらはいかがでしょう。」 | `sophie_counter_wrong2` |
| 違うよ③（お仕置き）| 「まあ、きっと、わたくしをからかっていらっしゃるんでしょう。では、これでもお聴きになってください。」 | `sophie_counter_oshioki` |
| メニュー見せて | 「お客様もせっかちですね。では、今夜のメニューをどうぞ。」 | `sophie_counter_menu` |

- ランダム候補（確率）：歌30/お酒20/NEWS15/この日15🔑/占い10🔑/お店5🔑/勝負5
- **違うよ**：×1・2でシャッフル、×3で **お仕置き** → YouTube自動再生（2vfCbdmKhMw）＋右メニュー4ボタン化
- **メニュー見せて**：クラシック4ボタン表示（3-B）

│ │   で歌をお届けします。         │ │
│ │   昭和の名曲にまつわる人生や    │ │
│ │   時代のお話も。               │ │
│ └──────────────────────────────┘ │
│ ┌──────────────────────────────┐ │  ← 緑
│ │   🎵 音楽リクエスト           │ │
│ │                              │ │
│ │   昭和の名曲を中心に600曲以上を │ │  ← 説明（紺）

## 3-D. DJプレイヤー（お酒紹介リンク付き）

後半パート（segments の2番目以降）再生時、`drinks` があれば下部にフェードイン表示。

```
┌──────────────────────────────────┐
│ ┌──────────────┐                 │
│ │ monitor      │ 🎙 DJ #006      │  ← モニター＋右上サムネ
│ │ YouTube歌 /  │ 昭和の歌謡史…    │
│ │ スライド     │ #006  2026-…     │
│ └──────────────┘                 │
│  ──────────────────────────────  │
│  🥃 今夜のお酒                    │  ← drinksがある時だけ
│  [ 🍶 アーリータイムズ         ]  │  ← タップでAmazon(新規タブ)
│  [ 🍶 I.W.ハーパー             ]  │
│  [ 🍶 メーカーズマーク         ]  │
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
│  [閉じる]  [⏭]  [⏹️]  [▶]        │  ← mode=dj_player
└──────────────────────────────────┘
```

- `drinks` 省略時は非表示。`amazon_url` 空の行はスキップ。
- 非表示：エピソード終了／別エピソード切替／一覧（D2）復帰時。
