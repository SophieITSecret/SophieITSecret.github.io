# TAKERU 速報パネルの設置手順（牧村さん用・一度だけ）

作成：2026-11-27　TAKERU担当（T）

11/28 の台湾選挙の開票速報を、HP トップの枠に出すための小さな仕掛けです。ソフィーが `TAKERU_共有\80_速報\` に置いた一番新しいファイルを、HP が読みにくる「窓口」になります。

所要：10分ほど。見張り番と同じ流れです。

## 1. プロジェクトを作ってコードを貼る
1. パソコンのブラウザで https://script.google.com を開く（牧村さんの Google アカウント）。
2. 「新しいプロジェクト」。左上の名前を「TAKERU 速報パネル」にする。
3. 最初からある `コード.gs` の中身を全部消し、`staging\TAKERU\editor\panel\Code.gs` の中身を全部貼る。
4. 💾（保存）。

## 2. フォルダの番号を入れる
1. 左の ⚙（プロジェクトの設定）→ 下の「スクリプト プロパティ」→「スクリプト プロパティを追加」。
2. プロパティ：`PANEL_FOLDER_ID`、値：`80_速報` のフォルダの番号。
   - ブラウザの Google ドライブで `TAKERU_共有` → `80_速報` を開くと、上の住所が `https://drive.google.com/drive/folders/1xT…` になる。その `folders/` の後ろの文字列です。
3. 「スクリプト プロパティを保存」。

## 3. 試しに動かす
1. 左の `< >` でコードの画面に戻る。上の関数の選びで `testLatest` を選び、▷「実行」。
2. 許可を求められたら、牧村さんのアカウントで許可する（「このアプリは確認されていません」→「詳細」→「（安全ではないページ）に移動」）。使う許可は「ドライブのファイルを見る」だけです。
3. 下の実行ログに `"file":"開票速報_0000試し.html"` と出れば成功です。

## 4. ウェブアプリとして出す
1. 右上の「デプロイ」→「新しいデプロイ」。
2. 左の ⚙（種類の選択）→「ウェブアプリ」。
3. 「次のユーザーとして実行」：**自分**。「アクセスできるユーザー」：**全員**。
4. 「デプロイ」。出てきた「ウェブアプリ」の URL（`https://script.google.com/macros/s/…/exec`）を写して、Claude Code に貼る。

これで終わりです。

## ふだん（11/28）
- ソフィーが30分ごとに `80_速報` に新しいファイルを置きます。HP は5分ごとに読み直すので、置いてから5分ほどで HP に出ます。
- **急いで消したいとき**：`80_速報` に `停止.txt`（中は空でよい）を置く。次に読んだときから、HP の枠が隠れます。戻すときは `停止.txt` をごみ箱へ。
- 11/29 の撤去も、まず `停止.txt` を置きます。そのあとホームくんが枠を外します。

## コードを直したとき
貼り直して保存したあと、「デプロイ」→「デプロイを管理」→ 鉛筆 →「バージョン」を「新しいバージョン」にして「デプロイ」。URL は変わりません。
