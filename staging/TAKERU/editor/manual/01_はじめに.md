# はじめに

作業台は、TAKERU のカード（本文・図・音声）とお知らせを直し、開発版と本番へ出すための道具です。このパソコンの中だけで動きます。

## 起動と終了

- **起動**：`editor` フォルダの `TAKERU作業台.bat` をダブルクリックします。黒い窓が開き、少しするとブラウザに作業台が出ます。
- **終了**：「⋯ その他」の「⏻ 終了」を押すか、黒い窓を閉じます。**保存していない直しは残りません。** 先に保存してください。
- 作業台のプログラムを直したとき（Claude Code が「作業台を開き直してください」と言ったとき）は、一度終了して、もう一度起動します。

## 上の段のボタン

| ボタン | 何をする所か | 説明の章 |
|---|---|---|
| 🔄 再読み込み | カードの一覧（CSV）を読み直す。ほかの所で直したあとや、表示がおかしいときに押す | — |
| 📰 お知らせ | アプリの「お知らせ」欄の文を、作る・直す・消す | お知らせ・閲覧状況・QR |
| 🧭 制作デスク | 新しいテーマのカードを、構想から本文まで作る | 制作デスク |
| 📥 搬入 | 自由研究の原稿（SSRI Monthly など）を受け取って、カードに入れる | 搬入 |
| 📮 マガジン | 毎週のマガジンの下書きを確かめて「OK」を出す | （この版には無い） |
| 𝕏 X | X の投稿の予定を見て、直して、承認する | （この版には無い） |
| 📝 原稿 | テーマごとの原稿ファイル（md）を開いて読む・直す | — |
| 👁 閲覧状況 | 本番のアプリが、どれだけ見られているかを見る | お知らせ・閲覧状況・QR |
| ⋯ その他 | あまり使わないボタン（進捗・会員・リンク集・QR など） | その他 |
| 📖 使い方 | この説明 | — |
| 💾 CSV を保存 | 直したカードを、手元のファイルに保存する（まだ利用者には出ない） | カードの基本作業 |
| 🚀 本番公開 | 保存した中身を、開発版と本番の両方へ出す | カードの基本作業 |

ボタンの上でマウスを止めると、短い説明が出ます。

## 開発版と本番

| | 住所 | 見える人 |
|---|---|---|
| 開発版 | `https://sophieitsecret.github.io/staging/TAKERU/` | 確かめ用。**公開の印の無いカードも出る** |
| 本番 | `https://takeru.ms-forum.com/` | 利用者。**公開の印のあるカードだけ**が出る |

- 「🚀 本番公開」を押すと、両方へ同時に出ます。
- 毎週土曜の朝、ニュースの自動取り込みも本番へ転送します。そのときは、それまでに GitHub に入っている中身も一緒に本番へ入ります。

## 困ったとき

- **表示がおかしい**：まず「🔄 再読み込み」。保存していない直しは消えるので、先に「💾 CSV を保存」。
- **間違えて保存した**：保存のたびに、前の形の控えが自動で残ります。
  - カードの CSV：`TAKERUcard_backup_日付_時刻.csv`（CSV と同じフォルダ。新しい30個）
  - 図：`editor\image_backup\`
  - 控えから戻すときは、Claude Code に「○時ごろの控えに戻して」と頼むのが確実です。
- **作業台が開かない**：黒い窓に「ポートは既に使用中」と出たら、作業台がもう動いています。ブラウザで `http://localhost:3000/` を開いてください。
