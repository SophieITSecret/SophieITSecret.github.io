# カードの基本作業

カードを1枚直して、利用者に届けるまでの流れです。

## 流れ（まとめ）

1. 左の一覧で、テーマを選び、カードを押す
2. 右の欄で、題・本文を直して **「✓ 適用」**
3. 図を入れるなら「🖼 画像を選ぶ」→ **「💾 画像を保存」**
4. 音声を作るなら、いちばん右の欄で **「🎙 録音」**
5. 出してよければ **「🌐 公開」** に印
6. 上の段の **「💾 CSV を保存」**（ここまでは手元だけ。利用者には見えない）
7. 上の段の **「🚀 本番公開」**（開発版と本番へ出る。数分かかる）

**「✓ 適用」と「💾 CSV を保存」は別です。** 適用は画面の中だけで、保存を押すまでファイルには書かれません。

## 左の一覧の見方

- 上の選ぶ欄でテーマを選びます。◀ ▶ で前後のテーマへ移ります。
- カードの右に、4つの印が並びます。色が付いていれば「ある」、灰色なら「まだ」です。

| 印 | 意味 |
|---|---|
| 公 | 公開の印が付いている（本番に出る） |
| 文 | 本文がある |
| 画 | 図がある |
| 音 | 音声（mp3）がある |

- 一覧の上の段には、テーマ単位のボタンがあります。
  - **✏️**：テーマ名・サブテーマ名を変える
  - **🎙 一括**：テーマの中の、音声の無いカードをまとめて録音する（録るカードを選べる。音声の無いカードに最初から印が付いている）
  - **🌐 公開**：テーマのカードを、まとめて公開／非公開にする

## 題と本文を直す

- 真ん中の欄が、アプリでの見え方の下見です。右の欄で直すと、すぐ下見に出ます。
- 本文の上に字数が出ます。
- 直したら **「✓ 適用」**。やめるときは「キャンセル」。
- 「📋 コピー」は、コード・題・本文をまとめて写します（AI に見せるときなど）。

## 図を入れる

- 「🖼 画像を選ぶ」で選ぶか、コピーした図を **Ctrl+V** で貼るか、真ん中へ落とします。
- どんな大きさの図でも、**960×720 の JPEG** に直して保存します（伸び縮みするので、横4：縦3の図がきれいです）。
- 下見を見て **「💾 画像を保存」**。前の図は `editor\image_backup\` に控えが残ります。
- 「SVGオーバーレイ」の欄に、Claude が作った SVG を貼ると、図の上に重ねて保存できます（空欄なら重ねません）。

## 音声を作る（VOICEPEAK）

いちばん右の欄です。

1. ナレーター、スピード・ピッチ、感情（喜び・楽しさ・悲しみ・怒り）を合わせます。設定は「スロット1〜3」に分けて覚えておけます。
2. **「🎙 録音」**：本文を読み上げた音声を作り、そのカードの音声として保存します。少し時間がかかります。前の音声は `voices_backup\` に控えが残ります。
3. 「▶ 再生」で聴きます。
4. 読み方を変えたいとき：
   - **「📝 読み修正」** を押し、読み上げ用の文を直してから録音します。本文の表示は変わりません。読み修正の文は自動で残ります。
   - 間を空けたい所に **【間】** を入れると 0.5秒の無音（【間】【間】で1秒）。
   - 終わったら **「✅ 確定」** で本文の表示に戻ります。
5. 「🔬 設定を比較」：1つの設定を少しずつ変えた3つの音声を作って、聴き比べられます。

音量は自動でそろえます。

本文の中の **「（出典：…）」だけの行は読み上げません**（アプリの画面には出ます。搬入が本文の最後に足す行。2026-11-20 から）。

## 🔤 読みと 🔎 検算（録ってから確かめる）

VOICEPEAK の読み違い（年代を数字のまま読む、F-35 を「マイナス」と読む、など）を減らす仕組みです（2026-11-19 から。ソフィーの R-20261119-S-16）。

**流れ（テーマ単位）**
1. 原稿を仕上げる
2. **「🎙 一括」** でテーマをまとめて録る。1枚ずつの確定は要りません。
   - 確定していないカードは、作業台が **年代と作業台の辞書の語を自動で置き換えた読み** で録ります（一覧の印「読🤖」）。
3. **「🔎 検算」** → 印のカードを検算。録った音声を Whisper が書き起こし、読ませた文と「音」で見比べて、ずれた所を出します。
   - 1枚 10〜20秒ほどかかります。行の ▶ で、その所から聞けます。
4. **「📤 ソフィーに仕分けを頼む」**。ソフィーがずれを1件ずつ仕分けて、`70_読み\返事\` に返します。
   - a：VOICEPEAK の読み違い／b：Whisper の聞き違い／c：表記のゆれ／d：原稿の誤り
5. 返事が来ると **「📥 ソフィーの仕分けを取り込む」** が出ます。
   - **a** の語は、辞書に「ソフィー案」として入ります。そのカードに **「🔁 録り直す」** の印が付きます。
   - **d** は、「原稿の直し」の一覧に出ます。本文を直したら「直した」を押します。
6. 録り直すカードだけ、「カードの読み」で紫の所を確かめて **「✅ この読みで確定」** → **「🎙 一括」**（録り直すカードに最初から印が付いています）。

**検算の限界**：Whisper は聞いた音を漢字に直して書きます。そのため、漢字の別の読み（金沢柵をカナザワと読んだ、など）は、ずれに出にくいです。その原稿に特有の固有名詞は、録る前に「📤 ソフィーに読みを頼む」で洗い出してもらえます（下）。

**検算の準備（初めの1回だけ）**：黒い画面で `python -m pip install faster-whisper fugashi unidic-lite` を打ちます。初めて検算するときに、Whisper のモデル（約480MB）を読み込むので、1枚目だけ長くかかります。

### カードの読み（1枚ずつ確かめるとき）

録る前に読みを確かめたいカード、録り直すカード、手で読みを直したいカードに使います。

- 左に本文、右に **読みの原稿**（VOICEPEAK に読ませる文）が出ます。右は手で直せます。
- 作業台が、決まりで自動に置き換えます（色が付きます）。
  - **年代**（緑）：1087年 → センハチジュウナナネン、1542〜43年、1980年代、紀元前221年 など。
  - **作業台の辞書の語**（青）：作業台の「読みの辞書」に足した語。
  - **要確認**（橙）：辞書に無いハイフン入りの型式（P-3C など）。読みを入れて **「辞書に足す」** と、次からは自動で置き換えます。
- 人名・地名・城の名前などの読みは、作業台には分かりません。録る前に知りたいときは、**ソフィーに洗い出してもらいます**（その原稿に特有の固有名詞と、変わった表現だけ）。
  1. 読み確認の左上の **「📤 ソフィーに読みを頼む」**。依頼が `TAKERU_共有\70_読み\依頼\` に置かれる。ソフィーが朝6時・夕18時の見回りで拾い、24時間以内に返事を置く（急ぐときは声をかける）。
  2. ソフィーの返事が `70_読み\返事\` に来ると、同じ所に **「📥 ソフィーの返事を取り込む」** が出る。押すと、語が「ソフィー案（未承認）」として入り、下書きに **紫** で当たる。読みがカタカナでないなど、形の悪い行は取り込まずに知らせる。
  3. カードを確定すると、そのカードで使ったソフィー案の語が認められ、正式に辞書に入る。使わなかった語は、読みの辞書の画面で「認める」か「消す」。
  - ソフィー案は、頼んだテーマのカードにだけ当たります。同じテーマの返事を取り込み直すと、前の未承認の分は入れ替わります。「🎙 一括」の自動の読みには、ソフィー案は使いません（確かめてから）。
  - ソフィーの決まりは `70_読み\読みの決まり.md`。
- 確定した読みは、そのカードの「読み修正」として保存されます。「🎙 一括」も「🎙 録音」も、この文を読みます。
- 確定した後に本文を直すと、そのカードは **「本文が変わった」（⚠）** になります。「🎙 一括」は、今の本文から自動の読みで録ります（手で直した読みは使いません）。手で直した読みを生かすなら、もう一度確定してください。
- 左の一覧の印：✅ 確定済み／⚠ 本文が変わった／📝 前からの読み原稿（確定の印なし）／・ 未確認。「🎙 一括」の一覧には「読✅・読📝・読🤖（自動の読み）・読⚠自動・🔁録り直す」が出ます。

**読みの辞書**（読み確認の画面の「読みの辞書」。2026-11-19 から、**正本は VOICEPEAK の辞書**）
- アクセントは VOICEPEAK の辞書にしか持てません。作業台が語をカタカナに置き換えると、VOICEPEAK はアクセントを自分の見当で付けます。だから、語は最後には VOICEPEAK の辞書に入れます。
- **VOICEPEAK の語**：VOICEPEAK の辞書の書き出し（.vdc2）を「📥 取り込む」で入れたもの。
  - VOICEPEAK の中で効いているので、作業台は置き換えません。
  - アクセント（●で直したものも）は、元のまま作業台に残ります。表の「アクセント」の欄に出ます。
- **作業台の語**：読み確認やソフィーの仕分け（a）で足した語。VOICEPEAK に入るまでの間、録音の前に作業台が置き換えます。
- **VOICEPEAK に入れる手順**
  1. 辞書の画面の **「📤 VOICEPEAK 用に書き出す（.vdc2）」**（ダウンロードのフォルダに保存されます）
  2. VOICEPEAK の辞書の画面で「辞書のインポート」→ そのファイル →「マージ」
  3. アクセントがおかしい語は、VOICEPEAK で●を動かして直す
  4. VOICEPEAK で「辞書のエクスポート」→ 作業台の「📥 取り込む」で取り込み直す。VOICEPEAK に入った語は、作業台の置き換えから外れます。
  - 書き出しには、VOICEPEAK の全部の語を元のアクセントのまま入れてあります。「置換」を選んでも消えません。初めの1回は、念のため VOICEPEAK で今の辞書を書き出して、控えにしてから読み込んでください。
  - 作業台で読みを変えた VOICEPEAK の語は、音の数が変わるので、書き出しではアクセントを平板に戻します。VOICEPEAK で直してください。
- 「このカードだけ」の語と、未承認のソフィー案は、書き出しません。
- 「方」「城」のような1文字の語は、作業台の辞書に入れないでください（「地方」の中まで置き換わります）。そういう語は、VOICEPEAK の辞書に直接入れます。

## 公開の印

- 右の欄の上の **「🌐 公開」** に印を付けると、本番に出るカードになります（保存と本番公開の後で）。
- 印の無いカードは、本番には出ません。開発版には出ます。作りかけを本番公開しても、利用者には見えません。

## 保存と本番公開

- **💾 CSV を保存**：直したカードを、手元の `TAKERUcard.csv` に書きます。前の形は控えが残ります。
- **🚀 本番公開**：保存した中身を、開発版（GitHub）と本番（takeru.ms-forum.com）の両方へ出します。
  - 出るもの：カードの CSV・お知らせ・リンク集・図・音声・カードの共有ページ。
  - 作業台のプログラムは出ません。
  - 保存していない直しがあると、注意が出ます。先に保存してください。
  - 終わるまで画面を閉じないでください。最後に記録が出ます。

## 気をつけること

- 本文の CSV は、表計算ソフトで開いて保存しないでください。本文の中の改行が崩れることがあります。直すのは作業台か、Claude Code に頼みます。
- 「📝 原稿」の画面（テーマごとの md の原稿）で直したものは、そこから本体のカードに反映させます。原稿の画面の中の説明を見てください。
