# お知らせ・閲覧状況・QR

## 📰 お知らせ

アプリの「ニュース・お知らせ」の、**お知らせ**の欄に出す文を作る画面です。

### 書き方

1. **「＋ 新規」** を押す（直すときは、左の一覧から選ぶ）
2. 右の欄に入れる

| 欄 | 書くこと |
|---|---|
| 日付 | お知らせの日付。一覧は新しい順に並ぶ |
| 種別 | ふつうは「お知らせ」。「ニュース（週次ダイジェスト）」はニュースの記事用 |
| タイトル | 60字まで |
| 本文 | 改行してよい。リンクは `[表示名](URL)` と書く |
| 公開する | 印を付けると本番に出る |

3. **「✓ この内容を反映」**（一覧に入る。まだファイルには書かれない）
4. **「💾 保存する」**（`news.csv` に書く。前の形は控えが残る）
5. **「🚀 本番公開」** で、利用者に届く

### 自動で入るもの

- **マガジンのお知らせ**：毎週土曜の自動取り込みが、最新号のお知らせ（「TAKERUマガジン ○月○日号が出ました」）を入れ、前の号のお知らせを消します。手で作らなくてよいです。
- **ニュースの記事**：毎週土曜に自動で取り込みます。「🌐 今週のニュースを取ってくる」「📥 ダイジェストを取り込む」は、自動が止まったときに手で取り込むためのボタンです。
- 一覧の上の「月 ＋／月 −／年 ＋／年 −」は、ニュースの記事に「月次」「年次」の印をまとめて付け外しするものです（ニュースの時間の層の分け方）。お知らせには使いません。

## 👁 閲覧状況

本番のアプリが、どれだけ見られているかを見る画面です。開くたびに本番から最新を取ってきます。

- **数字は、本番の記録を1日1回まとめたもの**です。今日の分は、すぐには出ないことがあります。
- 「⚠ 本番未接続」と出たら、本番から読めていません（ネットや SSH の具合）。「↻ 更新」でやり直します。

### いちばん上：直近7日

日ごとの回数の表です。

| 行 | 数えているもの |
|---|---|
| トップ | アプリが開かれた回数 |
| カード | カードが読まれた回数 |
| ニュース | ニュース・お知らせの記事が読まれた回数 |
| リンク | アプリの中のリンクやボタンが押された回数（リンク集・マガジン・登録の出口など） |
| 追加 | スマホのホーム画面に追加された回数 |

### 下の表：「対象」で切り替える

| ボタン | 中身 |
|---|---|
| 📕 カード | カードごとの閲覧回数。科目で絞れる。「累計一覧」と「📅 日別マトリクス」、並びは「テーマ順」と「閲覧の多い順」。「閲覧0を隠す」も選べる |
| 📰 ニュース | 記事ごとの閲覧回数 |
| 🔗 リンク | リンク・ボタンごとの回数。アプリの中のボタンは、次の名前で出る：`MAGAZINE`（マガジンの号の一覧）、`REG_NEWS`（ニュースの欄の登録）、`REG_COMPLETE`（読み終えた画面の登録） |
| 📣 専用リンク・X | 外から来た回数と、専用リンクが開かれた回数（下の「専用リンク」を見てください） |
| 🏠 ホームページ | ms-forum.com の見られ方 |

### 「📣 専用リンク・X」の読み方

- **↗ 外から来た回数**：出どころの印の付いたリンクから開かれた回数です。
  - 頭が出どころ、後ろが行き先です。例：`X_TOP`＝X の投稿からトップへ、`YT_CARD_ASAKA01`＝YouTube から朝霞の1枚目へ。
  - 出どころの印は `?src=` で付けます（x＝X、yt＝YouTube、hp＝ホームページ など）。
- **🔳 専用リンクが開かれた回数**：QR・メルマガ・X などの、研究やカードを直接開くリンクが使われた回数です。

## 🔳 QR（専用リンクと QR コード）

「⋯ その他」の中にあります。研究（自由研究の講座）やカード1枚を、トップを通らずに直接開く住所と、その QR コードを作ります。

- **研究のリンク**：左の一覧から研究を選びます。住所は `https://takeru.ms-forum.com/?study=<コードの頭>`（例 `?study=MSENSHI`）。
  - 講座にテーマがいくつかあるとき、`?study=頭` は**その講座の最初のテーマ**を開きます。ほかのテーマを直接開くには、そのテーマの最初のカードの `?card=`（例 `?card=UDG08`）を使います。
- **カード1枚のリンク**：上の欄にコードを入れて「探す」。住所は `?card=<コード>`（例 `?card=JPNDF12`）。メルマガの「ご存知ですか？」などに使います。
- QR の絵は、Dropbox の `タケルプロジェクト\マーケティング\QR\` に保存されます。チラシなどに使います。
- 読み取った人は、その研究の一覧・そのカードへ直接行けます。TOP や ▲ で、ふつうに戻れます。

### 専用リンクの印のまとめ

| 印 | 意味 | 例 |
|---|---|---|
| `?study=頭` | 自由研究の講座を開く | `?study=MSENSHI` |
| `?card=コード` | カード1枚を開く | `?card=ASAKA01` |
| `?view=画面` | 画面を開く（market・news・notice） | `?view=market` |
| `?src=出どころ` | どこから来たかを数える。上の印と一緒に付けられる | `?card=ASAKA01&src=yt` |
