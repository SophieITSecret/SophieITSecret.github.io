# 搬入（自由研究の原稿を受け取る）

『SSRI Monthly』などの原稿を、手を入れずに自由研究のカードにする仕組みです（2026-11-17 から）。

## しくみ（ひとことで）

- **講座**（例「歴史の中の戦争解説」・宇田川敬介）は、**牧村さんが作業台で1回だけ立てます。**
- **テーマ**（例「天下統一への城攻め」・5〜6枚）は、**ソフィーが置き場にフォルダごと入れます。** 何度でも足せます。
- 牧村さんは作業台で中身を見て、**取り込む**か**差し戻す**かを押すだけです。

アプリでは「自由研究 → 著者から → 宇田川敬介 の自由研究 → 歴史の中の戦争解説」と進み、講座の中でテーマごとに見出しが立ちます。

置き場：Google ドライブ `TAKERU_共有\60_自由研究の搬入\`

## 講座を立てる（新しい講座のときだけ）

1. 「📥 搬入」→ 左上の **「＋ 新しい講座」**
2. 入れるもの：

| 欄 | 例 | 説明 |
|---|---|---|
| 講座名 | 歴史の中の戦争解説 | アプリの講座の名前。受付のフォルダの名前にもなる |
| 著者 | 宇田川敬介 | アプリの「著者から」に出る |
| コードの頭 | UDG | 英大文字2〜8字。カードのコードは「頭＋番号」（UDG01, UDG02…）。ほかで使っていないか、その場で確かめる |
| 研究テーマ | 歴史;戦争 | アプリの「テーマから」の分け方。`;` で区切る |
| 出典の書き方 | 『SSRI Monthly』 | 本文の最後に「（出典：著者＋これ＋号）」の1行が付く。空なら付けない |

3. **「＋ この講座を立てる」**。置き場の `受付\<講座名>\` ができ、`講座一覧.md` に載ります。
4. ソフィーに「講座を立てたので、テーマを入れてください」と伝えます。

- 左の欄で講座の名前を押すと、講座の情報を見たり直したりできます。カードが入った後は、講座名とコードの頭は変えられません。
- 著者・研究テーマを後で直しても、もう入っているカードは変わりません（カードの画面で直します）。
- 同じ著者の別の連載なども、**新しい講座**として立てます。

## テーマを取り込む

1. ソフィーがテーマを入れると、左の欄の講座の下に、テーマが出ます。
   - ✅＝取り込める、⚠️＝直しが要る
2. テーマを押すと、右に次のものが出ます。
   - 振るコード（例 UDG07〜UDG12）
   - 確かめの結果（赤＝直しが要る、黄＝注意）
   - カードごとの、題・本文の頭・図の下見
3. よければ **「📥 CSVへ未公開で取り込む」**。
   - カードが**未公開**で CSV に入ります。
   - 図は 960×720 の JPEG になって入ります。
   - フォルダは `取り込み済み\<講座名>\` へ移り、決まったコードの一覧（`取り込み記録.md`）が置かれます。
4. 取り込んだら、カードの画面が読み直されます。あとはふだんどおりです：読む → 🎙 録音 → 🌐 公開の印 → 💾 CSV を保存 → 🚀 本番公開。

**コードは作業台が自動で振ります。** 講座の続きの番号です（UDG01〜06 の次のテーマは UDG07 から）。100枚目からは UDG100 のように3桁になります。

## 差し戻す

- 赤の「直しが要る」があると、取り込めません。
- 理由の欄に一言書いて **「↩ 差し戻す」**。
  - フォルダは `差し戻し\<講座名>\` へ移ります。
  - `差し戻し理由.md`（書いた一言と、自動で見つけた問題）が添えられます。
- ソフィーには「差し戻したので見てください」と伝えます。直したら、ソフィーが受付へ入れ直します。

## 同じテーマを直して入れ直したとき

- 同じ講座に同じテーマ名のフォルダが来ると、「出し直し」と出ます。ボタンは **「⚠ 置き換えて取り込む」** になります。
- 入れ替わるのは、**そのテーマのカードだけ**です。
  - 前のコードをそのまま使います。公開の印も残ります。
  - 枚数が増えたら、増えた分は講座の続きの番号になり、テーマの中に並びます。
  - 枚数が減ると、余ったコードのカードは CSV から外れます。取り込む前に知らせが出ます。公開中のカードが外れるときは「⚠」が付きます。
- 一度外したコードは、ほかのカードに使い回しません（外に出したリンクが、別のカードを指さないように）。

## うまくいかないとき

- **「フォルダが開かれていて移せませんでした」**：エクスプローラーなどでそのフォルダを開いていると移せません。閉じてからもう一度押します。このときは、CSV にも図にも、まだ何も入っていません。
- **「講座の立っていないフォルダが受付にあります」**：受付の直下に、講座の外のフォルダが置かれています。講座を立てるか、正しい講座のフォルダへ移します。
- **作業台のボタンが動かない**：作業台を開き直します（プログラムを直した直後など）。

## 「⋯ その他」の「📥 一括取り込み」との違い

| | 📥 搬入（この章） | 📥 一括取り込み（その他の中） |
|---|---|---|
| 使うとき | 自由研究の原稿を、図ごと受け取る | AI が書いた本文を、**今あるカード**にまとめて入れる |
| 入れ方 | 置き場のフォルダから | 画面に文を貼る（「#### コード　題」の区切り） |
| 新しいカード | 作る（コードも振る） | 作らない（今あるカードの本文を差し替える） |
