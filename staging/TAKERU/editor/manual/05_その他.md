# その他（「⋯ その他 ▾」の中）

あまり使わないボタンをしまってある所です。上の段の「⋯ その他 ▾」を押すと開きます。

| ボタン | 何をするか |
|---|---|
| 📊 進捗 | 科目・テーマごとに、本文・図・公開がどこまで進んだかを一覧で見る |
| 👥 会員 | TAKERU に登録した人（メルマガの宛先）を見る。**個人情報**（下の注意） |
| 📌 リンク集 | TAKERU 関係のサイト・管理画面・フォルダの住所を、押して開ける |
| 🔳 QR | 研究やカードを直接開く専用リンクと QR を作る（「お知らせ・閲覧状況・QR」の章） |
| 📝 メモ | AI に頼むときの依頼文のひな形を、名前を付けて置いておく |
| 📥 一括取り込み | AI が書いた本文を貼って、今あるカードにまとめて入れる |
| 📤 書き出し | カードの原稿と図を、人や AI に見せる形（MD・HTML）で書き出す |
| ⛶ 全画面 | 作業台を全画面にする（Esc で戻る） |
| ⬆ v○○ | アプリの版番号を1つ上げる |
| ⏻ 終了 | 作業台を終わらせる（黒い窓も閉じる） |

## 📊 進捗

- 科目ごとのタブで、テーマごとに「本文ができたか・図があるか・公開されたか」を並べて見ます。
- 次にどのテーマを作るか、どこが止まっているかを決めるときに使います。
- カードの「公」の印を押すと、公開の印を付け外しできます。変えたら「💾 CSV を保存」（ほかの印は見るだけです）。

## 👥 会員（個人情報）

**登録した人のメールアドレスです。画面を人に見せないでください。**

- 本番のサーバーにある名簿を、開くたびに読んで出します。手元にファイルは残しません。
- 「📋 メールをコピー」：アドレスだけを改行区切りで写します。
- 「⬇ CSV保存」：日付とアドレスのファイルを、ダウンロードフォルダに作ります。
  - MSフォーラムの「個人情報の保管方針」では、パソコンに落とすのは作業に要るときだけ、**終わったら消す**決まりです。
  - Dropbox・メール・チャットには置かないでください。
- この名簿は、会員システムがメルマガの宛先として毎回読んでいます。名簿の形や場所は、作業台からは変えません。

## 📌 リンク集

- TAKERU 関係のサイト・管理画面（Xserver、X 開発者コンソール、GitHub など）と、このパソコンのフォルダの住所を、名前を押して開けます。
- 足す・直す・消すは画面からできます。中身は Dropbox の `タケルプロジェクト\TAKERU 住所録.json` です。
- **パスワードや鍵は入れないでください。**

## 📝 メモ（プロンプトメモ）

- AI に頼むときの依頼文のひな形を、名前を付けて置いておけます。
- 写して、Claude やチャッピーに貼って使います。

## 📥 一括取り込み

- Claude や Gemini が出した文章を貼ると、カードごとに分けて、**今あるカード**の本文にまとめて入れます。
- 区切りは、行の頭の `@コード` か `#### コード　題` です。
- 入れる前に下見が出ます。CSV に無いコードは飛ばします（新しいカードは作りません。新しいカードは「📝 原稿」か「🧭 制作デスク」で作ります）。
- 入れたら「💾 CSV を保存」。
- 自由研究の原稿を図ごと受け取るのは「📥 搬入」です（「搬入」の章）。

## 📤 書き出し

- カードの原稿と図を、人や AI に見せる形（MD・HTML）で書き出します。
- Claude や ChatGPT に読ませるときは「MD だけ」が軽くて便利です。
- ファイルはダウンロードフォルダに保存されます。

## ⬆ 版番号

- アプリの版番号を1つ上げます。利用者のスマホに残っている古い図や音声を、新しいものに入れ替えさせたいときに使います。
- ふつうは、アプリのプログラムを直したときに Claude Code が上げます。単独で押すことは少ないです。
