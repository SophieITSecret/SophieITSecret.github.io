# TAKERU 見張り番の設置手順（牧村さん用・一度だけ）

作成：2026-11-19　TAKERU担当（T）
見張り番は、予定どおりに動いていないこと（X の投稿の遅れ・エラー、マガジンの遅れ、土曜のニュース取り込みの届かず、アプリの不調、期日の近いもの）を、1時間ごとに Google の上で確かめ、異常があれば Gmail で知らせます。パソコンが寝ていても動きます。

所要：10分ほど。マガジンのスマホ作業台と同じ流れです。

## 1. プロジェクトを作ってコードを貼る

1. パソコンのブラウザで https://script.google.com を開く（牧村さんの Google アカウント）。
2. 「新しいプロジェクト」。左上の名前を「TAKERU 見張り番」にする。
3. 最初からある `コード.gs` の中身を全部消し、`staging\TAKERU\editor\watch\Code.gs` の中身を全部貼る。
4. 💾（保存）。

## 2. スクリプトのプロパティ（住所と合鍵）を入れる

左の ⚙（プロジェクトの設定）→ 下の「スクリプト プロパティ」→「スクリプト プロパティを追加」で、次の6つを入れる。値は作業台の `editor\secrets.json` から写します（**この手順書や提出箱には値を書かないでください**）。

| プロパティ | 入れる値 |
|---|---|
| `X_GAS_URL` | secrets.json の `x` の `gasUrl` |
| `X_TOKEN` | secrets.json の `x` の `token` |
| `MAG_GAS_URL` | secrets.json の `news` の `gasUrl` |
| `MAG_TOKEN` | secrets.json の `news` の `token` |
| `ALERT_TO` | 知らせを受け取るメールアドレス（スマホの Gmail で見られるもの） |
| `WATCH_FOLDER_ID` | `今日の様子.md` を書くフォルダの番号（ID）。ブラウザの Google ドライブで `TAKERU_共有` → `20_見張り` を開くと、上の住所が `https://drive.google.com/drive/folders/1xT…` のようになる。その `folders/` の後ろの文字列（フォルダの番号。合鍵ではない）。Claude Code に「20_見張りのフォルダの ID を調べて」と頼んでもよい |

- 合鍵は、X の台帳とマガジンを書き換えることもできる鍵です。見張り番は読むだけですが、ほかの人に見せないでください。
- 期日表を変えたいときは、`DEADLINES_JSON` を足します（書き方は Code.gs の頭）。足さなければ、ガーディアンのキーの延長（2027-02-15 ごろ）だけを見ます。

## 3. 動かす

1. プロパティを入れたら「スクリプト プロパティを保存」を押し、左の端の `< >`（エディタ）でコードの画面に戻る。上の関数の選びで `setup` を選び、▷「実行」。
2. 許可を求められるので、牧村さんのアカウントで許可する（「このアプリは確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」。自分で作ったプログラムなので大丈夫です）。
   - 使う許可：外の住所を読む、Gmail で送る、ドライブのファイルを書く、時刻で動かす。
3. 次に `testAlert` を選んで「実行」。**スマホに「【TAKERU見張り】試しの知らせ」が届けば完了**です。
4. `TAKERU_共有\20_見張り\今日の様子.md` ができていることを確かめる。

これで、1時間ごとに自動で動きます。

## ふだん

- 何もなければ静かです。異常があるとメールが1通来ます。同じ異常は、片付くまで1日1回だけ知らせ直します。
- いまの様子は、いつでも `20_見張り\今日の様子.md` で見られます。ソフィーも6時・18時にここを見て、見張り番が止まっていないかを確かめます。
- 知らせの受け持ち：X・マガジン＝マガジン、ニュース自動取り込み・アプリ・作業台＝T、お金・ログイン＝牧村さん。

## コードを直したとき

T が Code.gs を直したら、1の3〜4と同じように貼り直して保存するだけです（プロパティと時刻の設定はそのまま残ります）。

## やめるとき

左の ⏰（トリガー）で `hourly` のトリガーを消す。
